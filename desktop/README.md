# 心晴3.0 Windows 桌面版

Windows 10/11 x64 安装程序与便携程序均由 GitHub Actions 生成。本机无需安装 Node、Java、Android SDK 或其他开发环境。

## 使用

1. 运行 `Xingqing-Desktop-1.0.0-Setup-x64.exe` 安装，或使用 `Portable-x64.exe`。
2. 「设置与同步」中填写手机已经使用的 CloudBase 环境 ID、同步用户名和密码，登录并合并同步。原环境的数据库和存储规则无需修改。
3. 登录凭证由 Windows 加密保存在本机。以后启动程序时自动恢复登录，修改后及运行期间自动同步；凭证过期且不能刷新时才需重新登录。离线可以继续编辑。
4. DeepSeek Key 需在电脑上单独填写。AI 对话、上下文设置、草稿和 Key 留在本机，不通过账号同步到手机。AI 建议需打开卡片、检查并保存后才成为记录。

## 功能

- 左侧导航、中间课表／日程、右侧详情编辑。浅灰底、蓝色高亮、圆角卡片。
- 课程支持多个星期、连续节次、上课周次和课表 JSON 导入导出，与 Android 格式一致。
- 日程按全天／上午／下午／晚上排列，可筛选全部／活动／心情；完成的任务和结束的课程收至底部。
- 持续任务折叠汇总，子任务可加入今天，完成状态共用；历史日期仅显示当日进展摘要。
- 重复任务单次或本次及以后编辑、DDL、多个可管理标签、长篇心情（支持展开写作）、五档表情和活力、最多9张照片。
- 原图导入后复制至内部照片目录，适当缩放；本机备份包含已下载照片、记录、草稿和对话，排除密钥与登录凭证。
- 独立 AI 对话、切换会话、上下文范围与历史条数、单条历史排除、显式选择照片、失败重试和停止回复。
- 程序运行时于08:30／14:30／19:30提醒未完成母任务及临近DDL，课前15分钟提醒。可选择关闭窗口后留在托盘。退出程序或电脑休眠时不调度提醒。

## 保存与同步

本机资料位于 Electron `userData` 目录的 `state.json`、`photos/`、`credentials.enc` 和 `backups/`。状态采用临时文件、同步落盘、原子替换和上一份完整备份；密钥使用 Windows safeStorage。安装版与便携版在同一 Windows 账号下共享应用资料。卸载保留资料。

沿用手机的 `courses:*`、`events:*`、`moods:*`、`labels:*`、`settings:timetable` 记录，以及同一个 `xq_sync_put` 接口和私有 `xq-photos` 桶。使用服务器版本号和三方合并，不依赖设备时钟判定覆盖；同字段冲突需手动选择保留版本。绑定后不能切换为其他同步账号，避免私密记录串入另一账号。

首次桌面测试通过模拟 CloudBase HTTPS 响应验证协议、双设备合并和凭证保存；最终还需在你自己的真实账号下验收手机与电脑互改及照片下载。

## 云端验证

工作流 `.github/workflows/desktop.yml` 依次执行依赖安装、图标生成、语法检查、Node逻辑测试、Playwright实际Windows窗口测试、NSIS／便携包编译、静默安装及安装后启动测试。发布安装包、SHA256和截图报告。依赖版本由云端生成的 `package-lock.json` 固定，测试专用注入入口仅在非打包程序且显式开启测试变量时存在。

渲染界面启用沙箱、上下文隔离和严格CSP，无Node权限或直接网络访问；主进程通过白名单IPC处理数据、文件和联网。开发版本尚未配置商业Windows代码签名证书，安装程序的发布者未验证。
